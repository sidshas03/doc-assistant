# Installing Northwind CLI

Northwind CLI needs Python 3.10 or newer. Install it with `pip install northwind-cli`. On macOS and Linux the binary is placed on your PATH as `nw`. Verify the install by running `nw --version`. Windows is supported through WSL only; native Windows is not supported.
