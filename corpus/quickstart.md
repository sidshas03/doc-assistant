# Quickstart

Create a project with `nw init my-pipeline`, which writes a starter `northwind.yaml`. Add a source and a destination to that file, then run `nw run` to execute the pipeline once. A first run over the sample data usually finishes in under ten seconds. Use `nw run --watch` to re-run automatically when the config changes.
